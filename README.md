# 窓訳（Madoyaku）

Windows上のゲームやアプリに透明な枠を重ね、枠内の画像をOpenAI Responses APIへ送り、翻訳を下部に表示する小さなWPFアプリです。

個人開発のシンプルな試作品です。機能や使い勝手は開発途中です。

[Windows x64版をダウンロード（ZIP）](https://github.com/opvelll/madoyaku/releases/latest/download/Madoyaku-win-x64.zip) · [最新版のリリース情報](https://github.com/opvelll/madoyaku/releases/latest)

![英文を翻訳範囲で囲み、原文と日本語訳を下部に表示した使用例](docs/images/translation-example.png)

英文を囲んで翻訳した例です。枠の下に読み取った原文と日本語訳を表示します。

## 現在できること

- 透明な翻訳範囲を移動・リサイズ
- ボタンまたは `Ctrl+Shift+T` で翻訳
- 長い原文・翻訳結果のスクロール表示と、ドラッグによる表示領域の高さ調整
- キャプチャ画像をOpenAIの画像対応モデルへ送信
- 基本プロンプト、ゲーム・人物・用語の補足情報、モデル、翻訳先を編集
- 直近の原文・訳文を次回の翻訳の文脈として利用
- ウィンドウ位置と翻訳設定を自動保存
- 配置アイコンから、位置・サイズ・結果欄の高さを名前付きで保存・呼び出し
- 設定画面からAPIキーを入力し、Windows資格情報マネージャーへ保存

## 配布版の起動

上のダウンロードリンク、または[GitHub Releases](https://github.com/opvelll/madoyaku/releases/latest)のAssetsから `Madoyaku-win-x64.zip` をダウンロードしてください。`Source code (zip)` は開発用のソースコードです。配布版には.NETを同梱しているため、.NET SDKやランタイムの別途インストールは不要です。

配布版はWindows x64向けのZIPです。ZIPを右クリックしてすべて展開し、展開された `Madoyaku` フォルダ内の `Madoyaku.exe` を起動してください。ZIPの中から直接起動したり、`Madoyaku.exe` だけを別の場所へ移動したりせず、同じフォルダにあるDLLと一緒に使用します。

通常は、起動後に次の手順でAPIキーを保存してください。

1. アプリの「設定」を開き、「OpenAI APIキー」に自分のキーを入力します。
2. 「このWindowsユーザーの資格情報マネージャーに保存する」にチェックを入れます。
3. 「保存」を押します。次回の起動時も保存したキーを使用できます。

更新するときはアプリを終了し、新しいZIPを以前とは別のフォルダへ展開して、新しい `Madoyaku.exe` を起動してください。設定JSONと保存済みAPIキーは配布フォルダとは別に保存されるため、同じWindowsユーザーなら引き続き使用できます。

配布ZIPには `Madoyaku.exe`、実行に必要なDLL、`LICENSE`、`はじめに.txt` が含まれます。配布物を作る方法は「ビルドと配布物の作成」を参照してください。

## ソースからの起動

ソースからの起動・ビルドにはWindowsと.NET 10 SDKが必要です。翻訳には、自分のOpenAI APIキーと、画像入力に対応した利用可能なモデルを設定してください。API利用料が発生します。

PowerShellでこのフォルダを開きます。

```powershell
dotnet run
```

APIキーは現在のWindowsユーザーの資格情報として保存され、通常の設定JSONには保存されません。保存のチェックを外した場合は、保存済みの資格情報を削除し、入力したキーをアプリ終了までだけ保持します。Windowsの「資格情報マネージャー」からも削除できます。登録名は `HonnyakuKun/OpenAI` です。

代替手段として、起動前に `OPENAI_API_KEY` 環境変数を設定することもできます。起動時に環境変数と保存済みの資格情報の両方がある場合は、環境変数を優先します。

## 使い方

1. ゲームをウィンドウ表示またはボーダーレス表示にします。
2. 透明領域を翻訳したい台詞に重ねます。
3. `Ctrl+Shift+T` または「翻訳」を押します。
4. 訳文がウィンドウ下部へ表示されます。

よく使うウィンドウ配置は、ツールバーの配置アイコン（▣）から「現在の配置を保存…」を選んで名前を付けて保存できます。保存済みの配置を選ぶと、位置・サイズ・結果欄の高さをまとめて復元できます。

設定は `%LOCALAPPDATA%\HonnyakuKun\settings.json` に保存されます。キャプチャ画像と過去の翻訳はディスクへ保存しません。

設定の保存先とWindows資格情報の登録名には、既存データとの互換性のため旧名称 `HonnyakuKun` を使用しています。

## APIへ送信する情報

翻訳を実行するたびに、次の情報をOpenAI APIへ送信します。

| 送信する情報 | 内容 |
| --- | --- |
| 今回のキャプチャ画像 | 透明な翻訳枠の内側に映っている画面。台詞以外の文字や画像も、枠内にあれば含まれます。 |
| 基本プロンプト | 設定の「基本プロンプト」にある翻訳指示。 |
| 翻訳先の言語 | 設定の「翻訳先」（例：日本語）。対象のゲーム名を指すものではありません。 |
| 自分で入力した補足情報 | 設定の「ゲーム・人物・用語の補足情報」に入力した文章。人物の口調、用語の訳し方などを翻訳に反映するために毎回送ります。空欄なら「指定なし」として送ります。 |
| 過去の翻訳 | 過去の原文と訳文の組。送る件数は設定で決まります。過去のキャプチャ画像は送りません。 |

このほか、選択したモデル名などのAPI処理設定を送り、APIキーを認証に使用します。

「ゲーム・人物・用語の補足情報」は、設定欄に自分で入力した文章のことです。ゲーム全体のストーリー、ゲームファイル、プレイ状況などを自動取得して送る機能はありません。ただし、今回の枠内画像・入力した補足情報・送信対象の過去の翻訳に含まれるゲームの情報はAPIへ送られます。

## 翻訳の文脈として保持・送信する過去の翻訳

過去の翻訳は「原文と訳文の組」を1件として数えます。設定した件数だけをアプリのメモリに保持し、次の翻訳でAPIへ送ります。キャプチャ画像は保持・送信しません。

| 項目 | 現在の動作 |
| --- | --- |
| 保持・送信する件数 | 設定画面の「翻訳に使う過去の翻訳数」で指定します。初期値は8件、設定できる範囲は0～50件です。 |
| 指定数より少ない場合 | 存在する過去の翻訳だけを送ります。初回は過去の翻訳を送りません。 |
| 0に設定した場合 | 過去の翻訳を保持・送信しません。今回の画像や補足情報は送ります。 |
| 件数を減らした場合 | 保存時に古い過去の翻訳を破棄します。あとで件数を増やしても復元しません。 |
| 「過去の翻訳をリセット」 | 保持中の過去の翻訳を全件消去します。表示中の原文・訳文と、設定の補足情報は残ります。 |
| アプリ終了時 | 過去の翻訳は失われ、ディスクには保存しません。 |

たとえば設定が8件なら、翻訳が成功するたびに直近8件だけを保持します。次の翻訳ではその8件の原文・訳文と今回の画像を送ります。設定を3件に変更して保存すると、直近3件だけが残ります。

ゲームや場面を切り替えて以前の翻訳を文脈に含めたくないときは、「過去の翻訳をリセット」を押してください。設定に入力した補足情報はリセットでは消えないので、必要に応じて別途変更・削除してください。翻訳中は設定とリセットを操作できません。

## ビルドと配布物の作成

```powershell
dotnet build
```

Releaseビルド、format検証、差分検証、Windows x64向けの自己完結発行、確認モードでの起動確認、ZIP作成をまとめて実行するには、次を使います。

```powershell
.\scripts\Publish-App.ps1
```

成功すると、次の2つが作成されます。

- `publish\Madoyaku\Madoyaku.exe` と実行に必要なファイル
- `publish\Madoyaku-win-x64.zip`（配布用）

配布用ZIPを作成するだけでなく、発行したフォルダのexeを実API通信なしで起動確認します。発行に失敗した場合は、既存の配布物を置き換えません。

## UI確認

WPFの見た目や操作を変更した場合は、PowerShellで次を実行します。

```powershell
.\scripts\Verify-Ui.ps1
```

このコマンドは確認専用の設定ディレクトリでアプリを起動し、実API通信なしで設定画面・ダミー翻訳・折りたたみ・過去の翻訳のリセットを操作して、実画面のPNGを `artifacts\ui-verification\<実行ID>` に保存します。`report.md` の全画像を確認した後、レポートに表示された `Complete-Verification.ps1` コマンドを実行すると、Releaseビルド、format検証、`git diff --check`、配布フォルダ作成、ZIP作成、発行済みexeの起動確認を行います。確認モードは本番設定とWindows資格情報に触れず、APIキーを入力しません。

## 現時点の制限

- 排他的フルスクリーンや一部のアンチチート環境では、通常のオーバーレイや画面取得が動かない場合があります。
- OCRをローカル実行せず画像を直接送るため、翻訳ごとに画像入力のAPI利用料が発生します。
- 連続監視と翻訳ログ保存はまだ実装していません。
